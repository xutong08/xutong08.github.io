四、代码块

行内代码直接用反引号包起来，比如 hexo server。

五、表格

命令 作用
hexo new "标题" 新建文章
hexo clean 清理缓存
hexo g 生成静态文件
hexo s 本地预览
hexo d 部署到 GitHub

六、写在最后

写博客不用追求完美，先写起来最重要。哪怕只是记录一个报错的解决方法，
以后搜索到的人也会非常感谢你。
